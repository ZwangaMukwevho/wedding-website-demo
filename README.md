# Wedding Website — Sedza & Lila 💍

Based on HTML theme [freehtml5.co wedding template](https://freehtml5.co/wedding-free-html5-bootstrap-template-for-wedding-websites)

To set the countdown date see below section in `js/clock.js`

````
  // Target future date/24 hour time/Timezone
  let targetDate = moment.tz("2026-09-05 10:00", "Africa/Johannesburg");
````

## Events

- **Betrothal:** 9 May 2026, 10:00 AM – 2:00 PM — Lutheran Church Shayandima, Thohoyandou, Limpopo
- **Wedding:** 5 September 2026, 10:00 AM – 2:00 PM — Lutheran Church Shayandima, Thohoyandou, Limpopo

## Running locally

```bash
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080)
